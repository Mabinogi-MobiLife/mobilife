# 모비라이프 플러그인

마비노기 모바일 팬 서비스 [모비라이프](https://mabimobi.life)를 AI 에서 쓰는 플러그인입니다. 원격 MCP 서버 `https://mabimobi.life/mcp` 와 스킬 묶음으로 되어 있고, Claude(Claude Code·Claude 앱)와 OpenAI(ChatGPT·Codex) 양쪽에서 같은 폴더를 씁니다.

## 할 수 있는 것

- **숙제**: 숙제도우미에 등록한 일일·주간 숙제를 캐릭터별로 요약하고, 끝냈다고 말한 숙제를 체크합니다.
- **드레스룸 코디**: 의상·외형·염색을 골라 코디를 만들고 계정에 저장합니다. 저장하면 사이트에서 3D 로 바로 열 수 있는 링크를 줍니다.
- **마이홈 배치**: 게임과 같은 배치 규칙으로 검증한 배치를 저장합니다.
- **데코 수집 현황**: 모은 개수·점수와 점수가 큰 미수집 데코를 알려 줍니다.
- **게임 정보**: 도감 검색, 거래소 시세·추이, 공지·이벤트·월드 상태, 각인 강화 비용, 마도저항 계획.
- **랭킹**: 종합·전투력·매력·생활력, 어비스(시즌별), 나이트메어 드릴, 길드 랭킹의 상위권과 캐릭터·길드 순위, 서버별 스텔라그램 월간 순위(이번 달·지난 달). "지난 시즌"·"이번 달" 같은 기간은 서버가 정하고 결과에 어느 기간을 봤는지 적어 줍니다.

## 스킬

| 스킬 | 언제 |
|---|---|
| `stylist` | 코디를 만들거나 고칠 때 |
| `myhome` | 마이홈 배치를 설계할 때 |
| `homework` | 숙제 요약·체크 |
| `market-advisor` | 시세 해석, 강화·마도저항 비용 |
| `today` | 직접 부르는 오늘 브리핑(숙제·이벤트·월드 상태) |
| `look` | 직접 부르는 코디 하나 만들기 |

## 연결

처음 도구를 쓸 때 모비라이프 로그인과 권한 동의 화면이 뜹니다. 허용하는 권한은 코디·배치 저장, 숙제 기록, 데코 기록 읽기, 게임 정보입니다. 연결은 [AI 연결](https://mabimobi.life/ai)에서 언제든 끊을 수 있습니다.

### Claude Code

```
claude plugin marketplace add <이 레포>/plugins
claude plugin install mobilife@mobilife
```

### Codex

```
codex plugin marketplace add <이 레포>/plugins
```

## 데이터

AI 가 저장한 코디·배치에는 AI 출처가 표시되고, 기존 항목은 사용자가 확인한 뒤에만 덮어씁니다. 개인정보 처리는 [개인정보처리방침](https://mabimobi.life/legal/privacy)을 따릅니다. 모비라이프는 넥슨의 공식 서비스가 아닙니다.
