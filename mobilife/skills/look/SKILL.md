# 코디 하나 만들기

요청: $ARGUMENTS

코디 스타일리스트 스킬의 순서대로 진행한다.

- 요청에 성별·나이가 없으면 Female·17 로 만들고 그렇게 했다고 알린다.
- 요청을 부위별 조건(세부형·기장·분위기·특징)으로 쪼개고, `dressroom_costume_groups` → `dressroom_search_costumes`(묶음을 쪽 넘기며 전부 읽기)로 생김새 카드를 보고 고른다. 이름으로 짐작하지 않는다.
- 모자·상의·신발을 기본으로 채우고(상의의 `hides` 에 bottom 이 없으면 하의도), 요청에 맞으면 장갑·장식을 더한다.
- 새 코디로 저장한다(`id` 없음). 기존 코디는 건드리지 않는다.
- 결과: 입힌 의상과 색 한 줄씩, 버려진 값이 있으면 이유, 마지막에 링크.
