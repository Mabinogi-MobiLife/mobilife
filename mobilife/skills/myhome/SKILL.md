# 마이홈 배치 도우미

게임과 같은 규칙으로 검증되는 마이홈 배치를 만들어 저장하고 링크를 준다. 서버 검증은 하나라도 틀리면 통째로 거절하므로, 작게 만들어 저장하고 넓혀 가는 편이 빠르다.

## 순서

1. **집 고르기.** `myhome_catalog`(검색어 없이) 로 집 목록을 보고, 사용자의 집을 묻는다. 기존 배치를 고치면 `myhome_list` → `myhome_get` 으로 `layout` 을 가져온다.
2. **구조 보기.** `myhome_home` 으로 바닥 칸(`rows[z][x]=='#'`), 현관, 벽 선(벽걸이 자리), 철거 가능한 벽을 본다. 격자는 0.5m 칸이다.
3. **데코 찾기.** `myhome_catalog(query=...)` 로 데코의 `key`·변형 id(`v`)·차지하는 칸(`cells`)·종류(바닥 가구·러그·벽걸이·탁상 소품·벽지·바닥재)를 얻는다. `where` 가 그 데코를 payload 의 어디(items · walls · finish)에 넣는지, `limit` 이 집 크기별 개수 상한을 알려 준다. key 를 지어내지 않는다.
4. **방 하나씩 배치.** 한 방(또는 가구 10~20개)씩 `items` 를 만든다.
   - `{i, k, v, x, z, d}`: `i` 는 1~65535 사이 유일 번호, `(x, z)` 는 피벗 칸, `d` 는 방향 0~3.
   - 차지하는 칸은 `(x,z) + R_d(c)` 로 계산한다. R_0(a,b)=(a,b), R_1=(b,-a), R_2=(-a,-b), R_3=(-b,a).
   - 바닥 밖·현관 칸·다른 가구와 겹치는 칸은 안 된다. 러그는 다른 러그와만 겹치면 안 되고 가구 밑에는 깔 수 있다. 탁상 소품은 바닥 가구 위에 놓인다.
   - 벽걸이: 벽 선 위, 벽과 같은 축, 앞 칸이 바닥이어야 한다.
   - 탁상 소품: `p=[부모 i, 스냅 번호]` 필수. 위치는 부모 위치 + 부모 데코 `snaps` 의 그 번호·부모 방향 칸이고, 스냅 하나에 소품 하나, 허용 크기 이하만.
   - 벽지·바닥재는 `finish: [{room, wallpaper?:[key,v], floor?:[key,v]}]` 로 방마다 하나.
5. **저장하고 고친다.** `myhome_save`. 거절되면 `reason` 에 나온 항목만 고쳐 다시 저장한다. 같은 실수를 반복하면 그 데코의 `cells` 와 방향 계산을 다시 확인한다.
   - 새 배치: `id` 를 비운다. 기존 배치는 통째로 바뀌므로 **사용자에게 먼저 확인**하고 `overwrite=true`.
6. **보고.** 방마다 무엇을 어디에 놓았는지 짧게, 마지막에 `link`.

## 꾸미기 요령

- 동선: 현관에서 각 방으로 가는 1칸(0.5m) 이상의 통로를 남긴다.
- 큰 가구를 벽에 먼저 붙이고, 러그로 영역을 나눈 뒤, 탁상 소품과 벽걸이로 채운다.
- 테마(예: 카페, 서재)를 받으면 같은 시리즈 데코를 먼저 찾는다(이름 검색).

## 하지 않는 것

- 검증을 통과하지 못한 배치를 "저장했다"고 말하지 않는다.
- 사용자가 고르지 않은 기존 배치를 덮어쓰지 않는다.
