# 모비라이프 AI 플러그인

[모비라이프](https://mabimobi.life)는 마비노기 모바일 팬 서비스입니다. 이 플러그인을 설치하면 Claude·ChatGPT 에서 모비라이프 계정의 숙제도우미, 드레스룸 코디, 마이홈 배치, 데코 수집 기록을 쓰고, 도감·거래소 시세·강화·마도저항 계산을 물어볼 수 있습니다.

- 플러그인: [`mobilife/`](mobilife/) — 원격 MCP 서버 `https://mabimobi.life/mcp`(OAuth 로그인) + 스킬
- 안내: https://mabimobi.life/ai

## 설치 (Claude Code)

```
/plugin marketplace add Mabinogi-MobiLife/mobilife
/plugin install mobilife@mobilife
```

처음 도구를 쓸 때 모비라이프 로그인과 권한 동의 화면이 열립니다.
